- LLMSemanticTool: use this to evaluate the SRP using LOC and method names.

Here’s how you typically reason:

Example:
Thought: I need to understand how complex this class is.
Action: CountLOCTool
Action Input: <class code>
Observation: 87

Thought: I also need to understand what the class does.

Action: LLMSemanticTool

- Reason: This class combines responsibilities for data persistence, messaging, and logging.
